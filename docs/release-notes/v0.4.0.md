دعم Linux و macOS. برنامج على Windows فقط لا يحتاج أي تغيير عند الانتقال من `v0.3.0`.

## ملف لكل نظام

```java
ReleaseSource.github("owner/app")
        .asset("*-setup.exe")
        .assetFor(Os.LINUX, "*-linux-{arch}.deb")
        .assetFor(Os.MAC, "*-macos-{arch}.dmg")
```

`{arch}` تُستبدل بمعالج الجهاز (`x64` أو `arm64`). الإصدار الذي ليس فيه ملف لنظام النسخة ومعالجها لا يُعرض
عليها إطلاقًا، فلا يرى أحد تحديثًا لا يستطيع تثبيته. قبل ذلك كانت نسخة Linux تُعرض عليها مثبّت Windows.

## التحديث على Linux و macOS

الزر يصير «تنزيل المثبّت»: يُنزَّل الملف ويُفحص حجمه و SHA-256 (وتوقيعه إن وُجد `signedBy`) ثم يُفتح بما يفتح
به النظام هذا النوع، ويكمل المستخدم التثبيت. البرنامج لا يُغلق نفسه. على Windows لا شيء تغيّر.

**لم يُجرَّب هذا المسار على جهاز Linux أو macOS حقيقي بعد**؛ جُرّب منطقه بالاختبارات وبمحاكاة النظام.

## غير ذلك

- إصلاح: نظام اسمه «Darwin» كان يُقرأ Windows لأن الاسم يحتوي «win».
- سكربت الإصدار: `OtherAssets` يجعل `-VerifyOnly` يقول هل الإصدار يحمل ملفات الأنظمة الأخرى.
- زر «موافق» في رسائل النافذة صار بلغة النافذة لا بلغة الجهاز.
- المثبّتات المقبولة: `exe`، `msi`، `deb`، `rpm`، `dmg`، `pkg`.
